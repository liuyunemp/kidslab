# pattern-caterpillar 知识断言

## 适用范围
- 长度 2–6 的重复单元，以颜色、形状、大小、数量、声音或动作表示；双规律分别以 2 和 3 为周期。数量关是数量组循环，不是无限递增数列。
- 自由摆放只推断已出现至少两次的 1–3 项重复单元；有限前缀不能唯一确定所有可能的数学规律。
- 简单 AB、ABC 的类别重命名不会形成新规则；有限结构遍历后允许循环。

## 知识断言
- [F1] 给定长度为 p 的重复单元，第 n 项（从 0 计）取单元中 n 除以 p 的余数所对应的项；延长序列保持这一重复关系。[S1]
- [F2] 颜色每 2 项循环、形状每 3 项循环时，两种属性合起来每 6 项回到初始组合。[S1]
- [F3] 在本课自由模式中，至少观察两轮且所有对应项相同才接受一个周期；这是对当前有限序列的重复检验，不是对任意后续项的唯一性证明。[S1]

## 来源
- [S1] 人民教育出版社《义务教育教科书·数学》一年级下册“找规律”（重复单元与按规律接续）；周期索引使用整数除法的商余关系。
