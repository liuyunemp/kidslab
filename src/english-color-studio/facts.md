# english-color-studio 知识断言

## 适用范围

- 覆盖 8 个颜色词的英文听读与图文对应，以及指认单色的整句 It's …。
- 不覆盖颜色混合、拼写默写、音标书写或教材单元顺序。

## 知识断言

- [F1] red（红色）、yellow（黄色）、blue（蓝色）、green（绿色）、orange（橙色）、purple（紫色）、black（黑色）、white（白色） 依次是红、黄、蓝、绿、橙、紫、黑、白的英文单词。[S1]
- [F2] 指认单数物品时用 It's + 颜色词；It's 是 it is 的缩写，例如 It's red. 意为“它是红色的”。[S1]
- [F3] 颜色词是形容词，修饰名词时通常放在名词前（a red car）；本课件只用 It's … 句式，不训练该语序。[S2]

## 来源

- [S1] Cambridge Dictionary 英文词条（如 https://dictionary.cambridge.org/dictionary/english/red ），逐词核对词义、词性与单复数形式。
- [S2] Cambridge Dictionary Grammar, “Adjectives: position”（https://dictionary.cambridge.org/grammar/british-grammar/adjectives-position ）：形容词通常放在所修饰名词之前。
