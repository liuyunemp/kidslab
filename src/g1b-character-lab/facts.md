# g1b-character-lab 知识断言

## 适用范围
- 汉字变变屋：8个可自由选择的代表性探索及自由操作，对应2024年审定人教教材。
- 语文不声称覆盖全部生字、全部课文逐段阅读；数学不使用负数、小数计数或超出100的计算。
- 完成表示经历一次操作闭环，不是知识掌握评定；绘图、人物和实验金额为课件自制示例。

## 知识断言
- [F1] 仅展示合法字形：氵与青组合为“清”（qīng），示例词“清水”；日与青组合为“晴”（qíng），示例词“晴天”。这不是任意部件组合成字的规则。 [S1]
- [F2] 仅展示合法字形：忄与青组合为“情”（qíng），示例词“心情”；讠与青组合为“请”（qǐng），示例词“请坐”。这不是任意部件组合成字的规则。 [S1]
- [F3] 仅展示合法字形：氵与包组合为“泡”（pào），示例词“水泡”；扌与包组合为“抱”（bào），示例词“拥抱”。这不是任意部件组合成字的规则。 [S2]
- [F4] 仅展示合法字形：丁与扌组合为“打”（dǎ），示例词“打球”；白与扌组合为“拍”（pāi），示例词“拍手”。这不是任意部件组合成字的规则。 [S3]
- [F5] 仅展示合法字形：马与虫组合为“蚂”（mǎ），示例词“蚂蚁”；义与虫组合为“蚁”（yǐ），示例词“蚂蚁”。这不是任意部件组合成字的规则。 [S4]
- [F6] 仅展示合法字形：又与鸟组合为“鸡”（jī），示例词“小鸡”；甲与鸟组合为“鸭”（yā），示例词“小鸭”。这不是任意部件组合成字的规则。 [S4]
- [F7] 仅展示合法字形：饣与包组合为“饱”（bǎo），示例词“吃饱”；⻊与包组合为“跑”（pǎo），示例词“跑步”。这不是任意部件组合成字的规则。 [S2]
- [F8] 仅展示合法字形：斤与口组合为“听”（tīng），示例词“听见”；乞与口组合为“吃”（chī），示例词“吃饭”。这不是任意部件组合成字的规则。 [S5]
