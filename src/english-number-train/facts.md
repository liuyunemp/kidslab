# english-number-train 知识断言

## 适用范围

- 覆盖 1–10 的英文数字词，以及 one block / two blocks 的单复数对比。
- 不覆盖 0、11 以上数字、序数词、拼写默写或算术训练。

## 知识断言

- [F1] one、two、three、four、five、six、seven、eight、nine、ten 依次表示 1 到 10。[S1]
- [F2] 数词与可数名词连用时，one 后接单数名词（one block），two 及以上接复数名词（two blocks）。[S2]
- [F3] 本课件把车厢里的积木数量与数字词一一对应，数量为 0 时不显示数字词。[S1]

## 来源

- [S1] Cambridge Dictionary 英文词条（如 https://dictionary.cambridge.org/dictionary/english/red ），逐词核对词义、词性与单复数形式。
- [S2] Cambridge Dictionary Grammar, “Nouns: singular and plural”（https://dictionary.cambridge.org/grammar/british-grammar/nouns-singular-and-plural ）：可数名词复数通常加 -s。
