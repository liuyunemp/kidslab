# 教材单元分组与知识顺序

核对日期：2026-10-16。基于 [分类核查](classification-audit.md) 中的 58 个明确年级课件，共使用 26 个已核对的教材版本，登记 184 个目录入口，其中 136 个直达已有探索活动。原有年级、科目和玩法保持不变。

## 页面规则

- 选定具体年级后，按教材 → 单元 / 章节 → 页码 → 同页知识次序显示；跨科目、上下册和教材版本各自分开。选择全部年级时保持一课一卡。
- 标题使用“第一单元”“第二单元”等教材编号。物理使用原书“第五章”等章节编号；欢乐购物街、时间在哪里、笔画名称表等未编号专题保留原名，不人为编单元。未出现的单元表示当前没有对应入口，不代表教材没有该单元。
- 单元内优先按核心知识所在纸质页码排序；多处来源采用本单元的核心页码，例如音序查字法用第三单元第34页，不用前置字母表第11页。同页用 lessonOrder，最后以稳定ID决定顺序。比大小桥接在百数地铁后，口算加法整体排在口算减法前。
- 有独立活动的17款探索课，卡片显示活动标题、所属课件、知识点和页码，链接带 activity 参数。直达入口不会自动操作、播放声音或颁发完成记录；切换活动会同步该参数，刷新保持当前活动及已有进度。非法活动ID忽略，沿用可恢复存档。
- 其余课件保留整课入口，标注“整课探索”。同一整课关联多个单元时，可在各单元找到同一入口；当前没有独立活动选择能力的课件，不宣称能直达课内某一题。
- 总数和侧栏继续按去重课件统计；分组标题另计“探索入口”。近期/最新仍筛选对应课件，具体年级内按教材顺序展示；全部年级保留原近期/最新排序。搜索支持单元名、知识点和活动标题，零结果保留筛选。
- 新课件若有年级但尚无单元映射，保留在“本年级其他课件”，不能从标签猜单元。当前58课均已映射。

## 数据与维护

- 源码目录：src/curriculum.json，books 记录版本、年级、科目、双语单元名与页码；courses 记录课件、单元、核心页码、同页顺序及可选的稳定活动ID。
- scripts/curriculum.mjs 只读校验目录与活动源数据，拒绝错误年级、科目、未知单元/活动、重复入口、越界页码与版本不一致。scripts/build.mjs 在统一构建时将校验后的 curriculum 字段加入课件清单。
- 不增加运行时网络请求或跨课件资源依赖。17个课件本地模型中的 openActivity 只使用现有选择与存档逻辑。源码同步仍使用已有 g1b-sync 流程；本轮未执行同步生成器。
