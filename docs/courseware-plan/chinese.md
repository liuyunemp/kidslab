## 教材与知识核对

- 识字与《对韵歌》参照人民教育出版社《义务教育教科书 语文 一年级上册》第一单元；原综合素材中的“雪对花”已纠正为课文原句“雪对风”。
- 拼音与笔画内容参照同册汉语拼音和识字单元；各课 `facts.md` 给出具体教授范围。句子列车仅给一种句式示例，不把它说成唯一语序。
- 诗画猜猜台的古诗诗句按教材原文；笔顺快车站的笔顺规则参照国家语委《现代汉语通用字笔顺规范》。
- 本轮用 2D 卡通画面与触控操作实现低龄上册游戏；下册探索见下。

## 一年级下册探索（2024年审定版）

新增八款，共64个探索活动。教材八个单元及八个园地均有明确承接，详见[逐关覆盖表](g1b-textbook-coverage.md)。关卡始终可选，发现靠实际操作记录，不设答题解锁或分数。

| ID | 课件 | 核心操作 |
| --- | --- | --- |
| g1b-character-lab | 汉字变变屋 | 换个部件，看看字怎样变。 |
| g1b-writing-workshop | 写字小工坊 | 从亮点出发，慢慢写一笔。 |
| g1b-word-world | 词语生活馆 | 把物件放到台上，让词语动起来。 |
| g1b-dictionary-house | 音序小书屋 | 翻首字母，再找音节和汉字。 |
| g1b-sentence-studio | 句子造景台 | 安排主角、地点和动作，再演一遍。 |
| g1b-poetry-theater | 古诗小剧场 | 动一动景物，让诗句慢慢出现。 |
| g1b-story-studio | 故事放映屋 | 移动故事片段，再播放看看。 |
| g1b-speaking-stage | 表达小舞台 | 把想说的话摆好，演给朋友看。 |

本轮使用独立本地 Three.js 场景、可收拢工具面板、中文教材文字与双语操作界面。`facts.md` 限定实际教授的代表字、词、诗与叙事线索；写字不按速度评分，表达不录音、不识别、不评分。
