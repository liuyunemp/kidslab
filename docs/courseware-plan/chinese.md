# 一年级语文独立游戏清单

> 首轮范围：人教版一年级上册识字与拼音。六个主题分别是主站课程卡片，每款一局完成八道不同任务后才通关；答错原地重试，重载后续玩，重玩切换题目组合。

| 课程 ID | 游戏 | 内容与操作 |
| --- | --- | --- |
| `g1-character-garden` | 汉字寻宝 | 看“天、地、人、日、月、水、火、口、耳、山”等字找图画，沿用原综合课的识字素材 |
| `g1-pinyin-tracks` | 拼音轨道 | 接声母、韵母、声调车厢，拼读对应汉字 |
| `g1-stroke-workshop` | 笔画工坊 | 手指沿起点和笔画方向描线，包含横、竖、撇、捺、点、提、折、钩 |
| `g1-word-post` | 词语邮局 | 把日常词语送到相应图画信箱 |
| `g1-rhyme-stage` | 对韵小剧场 | 依据《对韵歌》原文配对：云对雨、雪对风、花对树、鸟对虫、山清对水秀、柳绿对桃红 |
| `g1-sentence-train` | 句子列车 | 连接“谁—在哪里—做什么”三节车厢，练习这一种简单表达方式 |

旧 `g1-chinese` 网址保留为导航，课程卡片通过 `listed:false` 隐藏；旧课被误判的完成进度不迁移到六款新游戏。各游戏使用独立稳定任务 ID 与存档。

## 教材与知识核对

- 识字与《对韵歌》参照人民教育出版社《义务教育教科书 语文 一年级上册》第一单元；原综合素材中的“雪对花”已纠正为课文原句“雪对风”。
- 拼音与笔画内容参照同册汉语拼音和识字单元；各课 `facts.md` 给出具体教授范围。句子列车仅给一种句式示例，不把它说成唯一语序。
- 本轮用 2D 卡通画面与触控操作实现低龄游戏；语文下册主题另列后续规划，不计入本轮已完成数。
