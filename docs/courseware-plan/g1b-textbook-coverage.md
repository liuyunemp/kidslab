# 一年级下册教材覆盖表

教材锁定：人民教育出版社当前公开的2024年审定版，[语文](https://book.pep.com.cn/1211001102241/mobile/index.html)、[数学](https://book.pep.com.cn/1221001102241/mobile/index.html)。核对日期：2026-10-16。以下页码均为纸质页码，电子图片序号为纸质页码加6。

本轮新增10款、升级7款，共136个探索活动。覆盖各单元主要目标，不逐题复制教材，不把代表性识字和描写标为“掌握全部生字”。七巧板、找规律保留为拓展，不计作本版独立单元。

分类复核：上述17款保留 `g1b`，比大小桥移除旧 `g1a`；七巧板皮影戏与规律毛毛虫使用 `grades: []`，仅在全部年级显示。具体结论见 [逐课核查表](classification-audit.md)，分类源码的构建和 E2E 本轮留待统一执行。
